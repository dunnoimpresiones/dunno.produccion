# DUNNO PRODUCCIÓN — versión visual final + PWA

Subir a GitHub Pages estos archivos y carpetas:
- index.html
- app.js
- styles.css
- manifest.webmanifest
- sw.js
- icons/

No subir Code.gs a GitHub si el repositorio es público.

Después abrir la URL de GitHub Pages y elegir **Instalar aplicación** en Chrome/Edge.
